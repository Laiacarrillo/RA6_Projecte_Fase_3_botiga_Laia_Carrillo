# PixelCat Games · Fase 3 (RA6) · Laia Carrillo
- **Part A · JSON niat (`cataleg_niat.json`):** s'han ampliat els 8 jocs substituint les plataformes per un objecte `especificacions` (amb `plataformes`, `mida_gb` i `multijugador`) i afegint una llista d'objectes `opinions` (`usuari`, `puntuacio` i `comentari`) per representar jerarquies complexes.
- **Part B · API externa (`api_jocs.html` i `js/api_jocs.js`):** consum de l'API REST CheapShark mitjançant `fetch` i `async/await` per mostrar ofertes en temps real i filtrar un joc concret per codi.
- **Part C · Base de dades SQLite (`cataleg.sql` i `cataleg.db`):** creació de la taula `jocs` i inserció dels 8 registres adaptant les estructures niades (`generes` i `opinions`) a columnes de text.
- **Part D · Consultes SQL (`consultes.sql`):** execució de les 6 consultes de lectura i filtratge, així com la inserció, modificació i eliminació del joc de prova `JOC-999`.
- **Part E · Exportació a JSON (`jocs_bd.json`):** exportació de la taula `jocs` des de SQLite; a diferència de `cataleg_niat.json`, l'arrel és una llista directa `[ ... ]` (sense l'objecte envoltant `botiga` ni `jocs`) i els arrays/objectes niats queden guardats com a cadenes de text escapades.
- **Prova de `jocs_bd.json` a `cataleg_json.html`:** en carregar el fitxer al selector, la web mostra «falta la llista jocs» perquè espera trobar les dades dins de `dades.jocs`; si s'accedís als registres, les llistes guardades com a text (com `generes`) fallarien en aplicar mètodes d'array com `.join()`.
- **Reflexió sobre el canvi de format (JSON vs SQLite):** JSON permet representar dades jeràrquiques i llistes niades de forma natural i llegible, mentre que una base de dades relacional plana obliga a serialitzar o dividir en taules relacionades les estructures complexes, però a canvi ofereix integritat de tipus, claus primàries i consultes SQL molt més potents i ràpides.
- **Com obrir-ho:** descomprimeix la carpeta, obre `api_jocs.html` i `cataleg_json.html` amb un servidor local (com Live Server) per provar l'API i carregar els fitxers JSON, i obre `cataleg.db` amb DB Browser for SQLite per revisar les dades.
